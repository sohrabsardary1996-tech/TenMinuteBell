# Ten Minute Bell — راهنمای ساخت APK

این اپلیکیشن اندروید یک زنگ صوتی را هر ۱۰ دقیقه پخش می‌کند. برای ساخت فایل APK لازم نیست Android Studio روی رایانه نصب باشد؛ GitHub Actions می‌تواند آن را بسازد.

## ساخت APK با GitHub Actions

1. وارد حساب خود در https://github.com شوید یا حساب بسازید.
2. از علامت `+` بالا سمت راست، گزینه **New repository** را بزنید.
3. نامی مثل `TenMinuteBell` انتخاب کنید، حالت **Public** یا **Private** را انتخاب کنید و **Create repository** را بزنید.
4. در صفحه مخزن، **Add file → Upload files** را انتخاب کنید.
5. فایل ZIP پروژه را ابتدا روی رایانه استخراج کنید؛ سپس تمام فایل‌ها و پوشه‌های داخل پوشه `TenMinuteBell` را بکشید و در صفحه آپلود GitHub رها کنید. پوشه مخفی `.github` و فایل `.github/workflows/build-apk.yml` را حتماً نیز بارگذاری کنید. خود فایل ZIP را به‌تنهایی آپلود نکنید.
6. پایین صفحه روی **Commit changes** بزنید.
7. در مخزن، زبانه **Actions** را باز کنید و workflow با نام **Build Android APK** را انتخاب کنید. اگر اجرا نشده، **Run workflow → Run workflow** را بزنید.
8. وقتی اجرای workflow سبز شد، همان صفحه اجرای workflow را باز کنید. پایین صفحه بخش **Artifacts** را می‌بینید. روی `TenMinuteBell-debug-APK` بزنید تا فایل ZIP خروجی دانلود شود.
9. ZIP خروجی را استخراج کنید؛ فایل `app-debug.apk` داخل آن است. APK را به گوشی منتقل و نصب کنید. ممکن است لازم باشد اجازه نصب از همان منبع را در تنظیمات Android فعال کنید.

## نکات

- فایل APK خروجی، نسخه debug است و برای نصب شخصی مناسب است؛ برای انتشار عمومی در فروشگاه باید نسخه release امضا شود.
- برای اجرای زنگ در پس‌زمینه، برنامه یک اعلان دائمی نشان می‌دهد. در گوشی‌های Samsung، برای کاهش احتمال توقف سرویس، به Settings → Apps → Ten Minute Bell → Battery بروید و **Unrestricted** را انتخاب کنید.
- پس از نصب، برنامه را باز کنید و «شروع زنگ» را بزنید. اولین زنگ پس از ۱۰ دقیقه پخش می‌شود و سپس هر ۱۰ دقیقه تکرار می‌شود. با «توقف» می‌توان آن را متوقف کرد.
